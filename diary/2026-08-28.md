## Bugs Found and Fixed
- Key Parameter Mismatch in Artifact Storage: store_artifact called with keyword args rather than positional key.
  Fix: Aligned EvidenceStore with ArtifactStorage interface passing composite key '{task_id}/{evidence_id}'.
- Missing Size and Hash Attributes on Evidence Model: Model lacked size_bytes field during bundle extraction.
  Fix: Added size_bytes attribute and validated sha256_hash formatting with custom pydantic field validator.
- Unhandled BadZipFile on Tamper Verification: Corrupted zip archives raised unhandled ZipFile errors instead of ValueError.
  Fix: Wrapped zip archive parsing in try/except handling BadZipFile and asserting deterministic tamper rejection.

## Key Decisions and Architecture
- Evidence-First Enforcement: Findings without valid cryptographic evidence references are strictly rejected from reports.
- Non-Reversible Secret Scrubbing: All logs, evidence dumps, and reports pass through central vault redaction.
- Self-Contained Evidence Bundles: Standalone zip bundles allow air-gapped third-party cryptographic verification.

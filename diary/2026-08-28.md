## Bugs Found and Fixed
- ORM Lazy Load in Async Sessions: Many-to-many target set associations failed during async insert operations.
  Fix: Configured lazy='selectin' on TargetSet relationships and inserted association rows explicitly.
- Enum Validation in SQL Deserialization: Stored strings failed type check when reconstructing domain models.
  Fix: Explicitly instantiated typed enums (AssetCriticality, EnvironmentLabel) during database row mapping.
- Stale Test Fixture Mismatch: Crash recovery tests mutated in-memory instances without syncing the repository.
  Fix: Updated lifecycle manager tests to commit intermediate states through the repository prior to recovery.

## Key Decisions and Architecture
- Decoupled Persistence: Services interact solely through Repository protocols rather than raw database sessions.
- Resilient State Recovery: Process termination preserves all collected evidence while marking interrupted tasks FAILED.
- Dual-Backend Support: Configurable storage.backend setting allows seamless testing and production deployment.

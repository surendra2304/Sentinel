## Key Decisions & Architecture
- Uniform Schemas: CLI and API share identical Pydantic contracts and TaskLifecycleManager logic.
- Immediate Kill Switch: Task cancellation instantly interrupts running asyncio tasks and logs audit records.
- Crash Resilience: Startup recovery loop ensures zero tasks remain stranded in non-terminal states.
- SSE Telemetry: Real-time event streaming powered by dedicated task correlation queues on the event bus.
- Rate Limiting: Sliding-window rate limiter protects API endpoints against excessive bursts.

## Bugs I Found & Fixed
- **Task Model Attribute Mutation**: Task model lacked started_at and used EXECUTING status enum value.
  - *Fix*: Aligned Orchestrator to use TaskStatus.EXECUTING and updated_at timestamps.
- **MinIO Connection Handling in E2E**: Unavailable S3 endpoints caused unhandled connection refusal errors.
  - *Fix*: Enhanced storage factory with resilient fallback to LocalFileSystemStorage for local execution.
- **Planner Target URL Parsing**: Planner passed raw URLs to DNS lookups which resulted in resolution failures.
  - *Fix*: Added URL hostname parsing ensuring DNS lookups only target valid domain strings.

## Key Decisions & Architecture
- No-Bypass Governance: Autonomous Orchestrator cannot run any tool directly; all actions pass through PolicyEngine.
- Provider-Agnostic Planning: The HeuristicPlanner interface is modular and ready for LLM intelligence providers.
- Living Memory: Agents read and enrich structured TaskWorkingMemory rather than unstructured terminal text.
- Forensics Continuity: All autonomous runs produce verifiable Evidence, Findings, and Risk summaries.
- Closed-Loop Autonomy: Observations automatically trigger finding creation and dynamic risk recalculation.

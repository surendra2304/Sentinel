## Key Decisions & Architecture
- Six-Dimension Policy: Kill switch, target scope, action class, rate/intensity, credentials, human approval.
- Deny-by-Default: Any unlisted action class, disabled module, or ambiguous target is immediately denied.
- Zero-Tolerance Boundaries: Target smuggling via query parameters or embedded hostnames is rejected.
- Audit Completeness: Passwords, tokens, and private keys are redacted from audit entries before storage.
- Operator Governance: Human authorization gates are required for all destructive or high-impact actions.

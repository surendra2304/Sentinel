## Bugs Found and Fixed
- BOM Encoding: Subagent-written files used UTF-8 BOM causing SyntaxError U+FEFF on line 1.
  Fix: Rewrote all files using [System.IO.File]::WriteAllText with UTF8Encoding(false) no-BOM encoder.
- Fallback Router: LLMProvider 500 response raised httpx.HTTPStatusError, not caught by timeout handler.
  Fix: Wrapped in broad Exception catch so any non-2xx error triggers the fallback chain correctly.

## Key Decisions and Architecture
- No agent calls a model API directly - all reasoning flows through IntelligenceRouter.
- Secrets discipline: LLMProvider api_key is never logged, never serialised, never in evidence or reports.
- Default is fully offline: HeuristicProvider is the singleton default, LLMProvider injected via config.
- Quality review is pre-finalization: runs before task ends, not as an optional post-process.

## Key Decisions & Architecture
- Injection-Safe Sandboxing: All external tools run via argument lists with shell=False and strict size limits.
- Resilient Tool Fallbacks: Native asyncio socket scanner ensures network discovery works without external Nmap binaries.
- Automatic Evidence Capture: Every single tool run produces an immutable Evidence artifact linked to the Task.
- Concurrency Management: Semaphore-based global limits protect against resource exhaustion and rate-limit triggers.
- Immutable Chain-of-Custody: Evidence records are anchored directly to specific tool adapters and raw hashes.

## Bugs Found and Fixed
- Audit Chain Multi-Instance Divergence: Multiple logger instances in separate modules previously caused hash state divergence.
  Fix: Added atomic file refresh of the latest hash before appending, guaranteeing unbroken chain continuity across workers.
- Relative Path Resolution on Windows: Relative candidate paths across differing drive letters triggered commonpath errors.
  Fix: Joined relative candidate paths to sandbox root prior to resolving, guaranteeing strict sandbox containment.
- CapabilityError Catch Precedence: Generic JSON decoding exceptions previously masked invalid HMAC signature errors.
  Fix: Explicitly caught and re-raised CapabilityError before parsing exceptions, ensuring precise error reporting.

  Fix: Cleaned up imports in TasksPage.tsx, restoring clean Vite production builds.

- Cross-Platform Sandboxing: Ensured process group termination works seamlessly on both Linux and Windows environments.
